# Arvaraju Arunraju — Portfolio

Professional AI Engineer & Python Developer portfolio.

**Live site:** https://arunrajuuuu.github.io/arunraju-portfolio/

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repository is configured for GitHub Pages via GitHub Actions.

On every push to `main`, the site is built and deployed to:

`https://arunrajuuuu.github.io/arunraju-portfolio/`

## Structure

```
src/
  components/   # UI sections
  data/         # Skills, projects, experience content
  App.tsx
  main.tsx
  index.css
```
